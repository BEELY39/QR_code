# Base de géolocalisation de test

`GeoIP2-City-Test.mmdb` provient du dépôt officiel
[maxmind/MaxMind-DB](https://github.com/maxmind/MaxMind-DB), dossier `test-data/`
(licence Apache-2.0 ou MIT, au choix). Ses données sont **fictives** et servent uniquement aux tests
de `GeoIpResolver`. Exemple utilisé : `2.125.160.216` → Boxford, GB.

La base réelle de production (DB-IP Lite) n'est jamais versionnée : voir `qrcraft-api/README.md`.
