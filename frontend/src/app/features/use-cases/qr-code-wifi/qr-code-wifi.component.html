Ce que contient réellement le code

Un QR code Wi-Fi n'est pas un lien : c'est une courte ligne de texte normalisée, lue nativement par l'appareil photo d'iOS et d'Android. Aucune application à installer, aucun serveur consulté au moment du scan.

WIFI:S:NomDuReseau;T:WPA;P:MotDePasse;;
  • S: le nom du réseau, tel qu'il est diffusé.
  • T: le type de sécurité — WPA couvre WPA, WPA2 et WPA3, WEP l'ancien standard, nopass un réseau ouvert.
  • P: la clé du réseau.
  • H:true n'est ajouté que si le réseau est masqué. Ajouté à tort, il fait échouer la connexion sur iPhone.

iPhone et Android : ce qui marche

iPhone (iOS 11 et plus) — ouvrez simplement l'appareil photo et visez le code : une notification propose de rejoindre le réseau. Aucune application tierce n'est nécessaire.

Android (9 et plus) — l'appareil photo ou Google Lens détecte le réseau et propose la connexion. Sur certains modèles, il faut passer par Paramètres › Wi-Fi › scanner le QR code.

Si la connexion échoue — vérifiez la casse du nom du réseau, l'absence d'espace en fin de mot de passe, et le mode de chiffrement de la box. Une box configurée en WPA3 uniquement peut refuser une trame annonçant WPA : basculez-la en WPA2/WPA3 mixte, le mode par défaut de la plupart des opérateurs.

Imprimer le QR code sans le rendre illisible

La majorité des QR codes qui « ne marchent pas » sont des codes mal imprimés, pas des codes mal générés. Trois règles suffisent : exporter en SVG (un format vectoriel reste net à n'importe quelle taille, contrairement à un PNG agrandi), conserver la marge blanche autour du motif, et garder un contraste franc entre les points et le fond.

La marge blanche

Comptez l'équivalent de quatre modules (quatre « carrés » du motif) de blanc tout autour. Sans cette zone de silence, un cadre coloré ou une photo collée au bord empêchent la détection.

Le contraste

Points foncés sur fond clair. L'inverse — un code clair sur fond noir — n'est pas lu par tous les appareils photo. Évitez aussi les dégradés trop pâles sur les coins de repérage.

La distance de scan

Règle simple : la largeur du code doit faire environ un dixième de la distance de lecture. Un code de 3 cm se scanne à 30 cm ; pour une vitrine lue depuis le trottoir, visez 15 cm ou plus.

Sécurité : ce qu'il faut savoir avant d'afficher le code

Soyons clairs : le mot de passe est inscrit en clair dans le QR code. N'importe quelle application de scan affiche la clé au lieu de se connecter. Ce n'est pas un défaut de QRCraft, c'est le fonctionnement de la norme — c'est vrai de tous les générateurs.

La conséquence pratique est simple : un code affiché en salle équivaut à donner votre clé à tous ceux qui passent. C'est acceptable pour un réseau prévu pour ça, jamais pour le réseau qui porte votre caisse et vos ordinateurs.

La bonne pratique

Activez le réseau invité de votre box et générez le QR code à partir de celui-ci. Il isole les appareils des clients de votre réseau interne, et vous pouvez en changer la clé quand vous voulez sans reconfigurer un seul de vos équipements.

Côté QRCraft, le nom du réseau et le mot de passe ne quittent jamais votre navigateur : le code est calculé localement, rien n'est envoyé ni conservé.
