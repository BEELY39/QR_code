QR code statique ou dynamique : lequel choisir ?

C'est la seule décision qui compte vraiment avant d'imprimer, et celle qu'on explique le moins. Elle détermine si votre code fonctionnera encore dans cinq ans — ou s'il cessera de répondre le jour où un abonnement s'arrête.

Le statique

L'information est écrite à l'intérieur même du motif. Le téléphone lit le code et obtient directement l'adresse, le texte ou les identifiants du réseau Wi-Fi. Personne n'est consulté au passage.

https://monrestaurant.fr/menu

Conséquence directe : rien ne peut tomber en panne entre le code et sa destination, et rien ne peut être facturé plus tard. En contrepartie, changer la destination impose de regénérer et réimprimer.

swap_horiz

Le dynamique

Le motif ne contient qu'un lien court vers le serveur du prestataire, qui redirige ensuite vers la vraie destination. Cette redirection est ce qui permet de modifier la cible après impression et de compter les scans.

https://un-service.com/r/7fK2p

Cette souplesse a un prix : chaque scan, pour toujours, dépend d'un tiers. Si le compte expire, si l'offre change ou si le service ferme, les codes déjà imprimés cessent de fonctionner.

Le piège classique

Beaucoup de générateurs proposent le dynamique par défaut, parfois sans le nommer : on crée un code « gratuit », on imprime cinq cents flyers, et l'on découvre quelques semaines plus tard que la lecture est limitée, que le suivi est réservé à une offre payante, ou que le code a été désactivé faute d'abonnement.

Le problème n'est pas le modèle économique — un service de redirection a un coût réel et légitime. Le problème est de l'apprendre après l'impression. Un code dynamique est un engagement dans la durée, pas un fichier que l'on télécharge et que l'on oublie.

Règle simple : si vous ne pouvez pas dire qui paiera la redirection dans trois ans, ne construisez pas votre affichage dessus.

La souplesse sans la dépendance

Il existe une troisième voie, rarement expliquée : encoder en statique une adresse que vous contrôlez.

  1. Utilisez une adresse de votre propre domaine, par exemple monrestaurant.fr/menu.
  2. Générez un QR code statique pointant vers elle, et imprimez-le.
  3. Le jour où le menu change, modifiez la page ou redirigez-la : le code imprimé, lui, ne bouge pas.

Vous gardez la possibilité de changer de destination, vous mesurez les visites avec vos propres statistiques, et plus personne d'autre ne peut éteindre vos codes.

Quand le dynamique est le bon choix

Soyons justes : le dynamique n'est pas une arnaque, c'est un outil adapté à certains cas. Il devient pertinent dès que la redirection et la mesure valent leur coût.

Campagnes courtes

Affichage publicitaire, opérations saisonnières, salons : la destination change d'une semaine à l'autre et le support est réimprimé de toute façon.

Mesure fine

Quand il faut comparer le rendement de plusieurs supports physiques — vitrine, flyer, packaging — avec des chiffres par emplacement.

Volumes industriels

Traçabilité produit, codes uniques par article, intégration à un système existant : le statique ne suffit plus.

Pour un menu, un Wi-Fi, une page de contact, un avis Google ou un profil Instagram — c'est-à-dire l'écrasante majorité des besoins d'un commerce — le statique est plus sûr, gratuit, et définitif. QRCraft ne génère que des codes statiques, et c'est un choix assumé.
