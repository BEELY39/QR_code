Vos données ne quittent pas votre navigateur

QRCraft fonctionne intégralement côté client : le QR code est calculé sur votre appareil, par le code JavaScript chargé avec la page. Ce que vous saisissez n'est ni transmis, ni stocké, ni consulté.

Ce que nous ne collectons pas

  • check_circle Le contenu encodé : liens, textes, noms de réseaux Wi-Fi et mots de passe. Ces valeurs restent en mémoire dans l'onglet et disparaissent à sa fermeture.
  • check_circle Les logos que vous importez : l'image est lue localement pour être incrustée au centre du code, jamais téléversée.
  • check_circle Aucun compte n'est requis, donc aucune adresse e-mail ni mot de passe de compte n'est demandé.
  • check_circle Aucun cookie publicitaire, aucun traceur de mesure d'audience, aucun profilage.

Vérification simple : coupez votre connexion après le chargement de la page. Le générateur continue de fonctionner, y compris le téléchargement des fichiers.

Ce qui transite malgré tout

L'hébergeur (Netlify) enregistre, comme tout serveur web, les requêtes techniques nécessaires à la diffusion du site : adresse IP, date, page demandée, type de navigateur. Ces journaux servent au fonctionnement et à la sécurité, pas à vous identifier.

Les polices et icônes sont chargées depuis Google Fonts. À cette occasion, votre adresse IP est transmise à Google pour servir ces fichiers. C'est la seule ressource tierce du site.

Une mise en garde honnête sur les QR codes Wi-Fi

Le mot de passe que vous encodez n'est pas chiffré : il est inscrit en clair dans le motif, comme le veut la norme. N'importe quelle application de scan peut l'afficher au lieu de se connecter. Ce n'est pas propre à QRCraft, c'est le fonctionnement du format — d'où notre recommandation d'utiliser le réseau invité de votre box pour tout code affiché en public.
